# 🏗️ Рефакторинг в чистую архитектуру с 44-параметрической векторизацией

## 📋 Обзор изменений

Система была полностью переработана для соблюдения принципов чистой архитектуры и оптимизации под UMAP с 44-параметрическими векторами.

## 🎯 Решенные проблемы

### ❌ Проблемы старой архитектуры:
- **Смешивание ответственности**: Marker знал о MA данных
- **Агрегированные параметры**: 16 усредненных характеристик
- **Слабая детализация**: Потеря информации о конкретных свечах
- **Нарушение SRP**: Одни компоненты решали несколько задач

### ✅ Новая архитектура:
- **Разделение ответственности**: Каждый компонент решает одну задачу
- **44 конкретных параметра**: Детальное описание каждой свечи
- **Модульность**: Легко тестировать и расширять
- **Оптимальность для UMAP**: Идеальное количество параметров

## 🔧 Компоненты архитектуры

### 1. 🎯 Marker (domain/marker.py)
**Ответственность**: Поиск паттернов в ценовых данных
```python
marker = Marker(a_len=8)  # Только длина прелюдии
segments = marker.mark(df)  # Работает только с OHLCV
```
- ✅ Не знает о MA данных
- ✅ Работает с любыми ценовыми данными
- ✅ Фокусируется только на поиске трендов

### 2. 📊 PatternCharacteristics (domain/models/pattern_characteristics.py)
**Ответственность**: Хранение 44 параметров паттерна
```python
# 44 параметра:
# - 24: форма свечей (body + тени)
# - 8: относительное расположение
# - 8: объемы
# - 4: MA контекст
```

### 3. 🧮 Vectorizer (services/vectorization/simple_vectorizer.py)
**Ответственность**: Извлечение MA данных и векторизация
```python
pattern_vectors = get_pattern_vectors_with_ma(df)
# Находит MA значения для каждого сегмента
# Обновляет характеристики с MA данными
# Возвращает 44-параметрические векторы
```

## 📈 Структура вектора (44 параметра)

| Индексы | Параметры | Описание |
|---------|-----------|----------|
| 0-7 | `body_ratios` | Размер тела / полная длина для каждой свечи |
| 8-15 | `upper_shadow_ratios` | Верхняя тень / полная длина |
| 16-23 | `lower_shadow_ratios` | Нижняя тень / полная длина |
| 24-31 | `relative_positions` | Позиция середины свечи относительно первой |
| 32-39 | `relative_volumes` | Объем свечи / средний объем |
| 40-43 | `MA parameters` | MA50/200 позиция и тренд |
