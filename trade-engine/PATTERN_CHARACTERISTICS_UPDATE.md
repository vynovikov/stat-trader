# Обновление системы PatternCharacteristics до 44 параметров

## Обзор изменений

Система векторизации паттернов была полностью переработана для использования **44 конкретных параметров** вместо 16 агрегированных характеристик.

## Новая структура вектора (44 параметра)

### 1. Форма свечей (24 параметра)
Для каждой из 8 свечей прелюдии:
- `body_ratio_i` = размер_тела / полная_длина_свечи
- `upper_shadow_ratio_i` = верхняя_тень / полная_длина_свечи
- `lower_shadow_ratio_i` = нижняя_тень / полная_длина_свечи

### 2. Относительное расположение (8 параметров)
Для каждой из 8 свечей:
- `relative_position_i` = (mid_price_i - mid_price_0) / range_всей_прелюдии

### 3. Объемы (8 параметров)
Для каждой из 8 свечей:
- `relative_volume_i` = volume_i / средний_объем_прелюдии

### 4. MA контекст (4 параметра)
- `ma50_position` = (close[0] - MA50[0]) / MA50[0]
- `ma200_position` = (close[0] - MA200[0]) / MA200[0]
- `ma50_trend` = (MA50[7] - MA50[0]) / MA50[0]
- `ma200_trend` = (MA200[7] - MA200[0]) / MA200[0]

## Преимущества новой системы

1. **Детальность**: Каждая свеча описывается индивидуально
2. **Оптимальность для UMAP**: 44 параметра - идеальный диапазон для UMAP
3. **MA интеграция**: Контекст глобального тренда через скользящие средние
4. **Нормализация**: Все параметры относительные, устойчивы к масштабу цен
